# English Learning App

An interactive web application for learning English through flashcards and an interactive reader. Built with Next.js, TypeScript, and Tailwind CSS.

## Features

- **Interactive Reader**: Read and analyze English text with real-time word/phrase explanations
- **Flashcard System**: Create and review flashcards with spaced repetition
- **Learning Settings**: Customize hint levels and translation detail
- **Progress Tracking**: Monitor your learning progress with mastery levels and review statistics

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up environment variables:
   - Copy `.env.example` to `.env.local`
   - Add your OpenAI API key
   
4. Run the development server:
   ```bash
   npm run dev
   ```

## Tech Stack

- Next.js 13+ (App Router)
- TypeScript
- Tailwind CSS
- OpenAI API
- Prisma (Database ORM)
